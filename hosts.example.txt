# Host list for Invoke-EvidenceCollection.ps1 -HostList
#
#   .\Invoke-EvidenceCollection.ps1 -HostList .\hosts.txt -OutputRoot D:\Evidence\Enclave-A
#
# One target per line. Blank lines and lines starting with # are ignored.
#
#   target                      host, user@host, or user@host:port
#   [platform]                  optional second word: windows, linux, or auto
#
# Leave the platform off (or write auto) and the target is probed over SSH before
# anything is copied to it. Name it to skip the probe - useful when you already know,
# or when a hardened host answers the probe in a way that cannot be classified.
#
# Hosts are collected one at a time, in this order. A host that fails does not stop
# the run; it is recorded as Failed in the manifest and the next one starts.
